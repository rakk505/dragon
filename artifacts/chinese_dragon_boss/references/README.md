# Chinese Dragon Reference Notes

The model is an original Minecraft-style interpretation. The generated
`chinese_dragon_concept.png` is the direct reconstruction reference. It was
authored for this project as hard-edged pixel art by
`../work/render_concept.py`; it does not copy a third-party game asset.

Open-access historical sources guided the anatomy and motion:

- Smithsonian National Museum of Asian Art, *Eleven Dragons*, F1919.173,
  CC0: <https://asia-archive.si.edu/object/F1919.173/>
- Cleveland Museum of Art, *Mirror with a Coiling Dragon*, 1995.367, CC0:
  <https://www.clevelandart.org/art/1995.367>
- The Metropolitan Museum of Art, *Dragon*, 14th century, 36431, Open Access
  public domain: <https://www.metmuseum.org/art/collection/search/36431>

The supplied Google Images URL was treated as a mood-board query only because
its client-side fragment is not a stable, attributable source.

Design cues retained: a wingless serpent body, ox-like head, deer antlers,
large eyes, lion mane, long whiskers, carp-scale color breakup, four eagle-
clawed legs, a tapered flame tail, and a pearl motif for charged attacks.
